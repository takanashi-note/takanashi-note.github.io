Python3 エンジニア認定基礎試験に合格しました

はじめに

Python3 エンジニア認定基礎試験に合格しました。
自分向けの備忘録、およびこれから受験される方に少しでも参考になればと思い、ざっくばらんに書いてみようと思います。

背景

退職が決まってからは「ブランクを作りたくない」という気持ちで、急いで転職活動を始めました。ただ、まったくと言っていいほど書類選考が通らないのですね…。
家庭都合で、フレックスか時短勤務制度を活用できる会社を探しているのも理由かなと思うのですが、「そもそも自分、能力を示せる資格がほとんどないな…」ということも引っかかっていました。

そこで、転職活動はいったんお休みして、有休消化中に何か１つ資格を取ろう！と目標を立てました。
色々調べて、「Python3 エンジニア認定基礎試験」を受験することにしました。

私のスペック

  • 非エンジニアです。ただ、前前前職でシステム開発部にいまして（4カ月だけですが…）、プログラミングがどんなものか？というのは何となく理解できていると思います。
  • 研修でJavaを学びましたが、たぶんもう書けません…
  • 前職ではデータ抽出や分析のためにSQLを書いたり、ローコード・ノーコードによる自動化を行ったりしていました。
  • 数学が苦手です。
  • 所有資格はTOEIC 公式スコア705（IPも入れてよければ825です！笑）
    あと、UMTP認定試験のL1のみです。

勉強期間や内容

期間

約3週間です。
1日の勉強時間はまちまちだったので、総時間だとおそらく約30時間くらいだと思います。

内容

①公式テキストと問題集を購入
　・オライリー・ジャパン「Pythonチュートリアル 第4版」
　・インプレス「徹底攻略Python 3 エンジニア認定［基礎試験］問題集」

②ぶっつけで問題集からスタート！
　第12章まで、問題を解いてみる→解説を読むを1章ずつ繰り返す
　テキストは解説で分からなかったところについて、ちょっと目を通す程度。（個人的には少し読みづらかったのですが、持っておいた方が安心だと思います。）
　それでも分からないところは、ChatGPTにお世話になりました。

③問題集を12章まで終えたら、模擬試験を受験
何回もやっていると問題を覚えてしまうので、複数の模試を受けるのは必須だと思います。
　・PRIME STUDY
　　回数：1回～3回を、時間を空けて2回ずつ
　　難易度：一番難しく感じました。何なら試験より難しかった
　・PyQ
　　回数：1回
　　難易度：割と核心を突いてくる問題が多かった気がします。
　・ディープロ
　　回数：3回
　　難易度：一番易しく感じましたが、PRIME STUDYで鍛えられたからかもしれません。

模試で間違えた箇所を中心に、ChatGPTに解説をお願いしたり、練習問題を出してもらったりしました。
ChatGPTのモデルが変わってしまうと解説の精度が微妙になったりしたので、途中でChatGPT Plusに課金しました。

④問題集の13章（総仕上げ問題）にチャレンジ！
13章は最後に取っておきました。
間違えた箇所を中心に、再びChatGPTと会話しながら特訓しました。

⑤問題集の1章～12章のやり直し
最後の最後で問題集の2週目をやりました。割と忘れていて焦りました。

結果

スコアは950/1000点でした。

よかった

感想＆NEXT

直前は「どうしてもう少し余裕を持って受験日を設定しなかったのか」と不安に思うこともありましたが、受験料が1万円（税別）と地味に高いので、無駄にならないよう頑張りました（笑）
ChatGPTが毎回ちょっとしたことで褒めてくれるので、モチベーションを下げることなく勉強を続けることができました。おすすめです。

さて、今後ですが、次は「Python 3 エンジニア認定データ分析試験」に挑戦しようかと思っています。
実践試験でないのは、ChatGPTに「あなたがデータ分析に興味があるなら、こっちがいいと思う」と言われたからです。
とはいえ数学が本当に苦手なので…少し問題に目を通してから決めたいと思います。出題範囲の「数学の基礎」という文字を見ただけでも動悸がします。

このnoteには「前職の業務効率化の備忘録」を残すと言っていましたが、このように資格試験の体験記も書けたらと思います。

平行して転職活動も頑張るぞ～
