【GAS】スプレッドシート内の特定列の値を一括消去する

お久しぶりの投稿です。たかなしです。

最近、仕事でGAS (Google Apps Script) を利用しています。
元々、GASの経験はほとんどなくて、5年前くらいに家族の要望で「受付画面で受付→来客をSlackに通知する」のような簡易システムを作った程度です。

5年越しにGASと再会したことで、作ってみたものや悩んだこと、工夫したポイントなどをまとめておきたいと思いました。

少しずつ開発(と言っていいレベルなのか微妙ですが)したものをここに残していこうと思います。

今回は「スプレッドシート内の特定列の値を一括消去する」スクリプトについて書きます。

1．課題が発生した背景

今所属しているチームでは、週次で行っているスプレッドシート上の作業があります。

作業の説明を少しすると、
・同じシートを毎回使いまわしています。
・一部の列では、前週の内容を削除して、今週の内容をコピーペーストしています。前週の内容は、作業者の任意のタイミングで削除しています。
・一部の列は、複雑な関数が入っているため、消してはいけません。
・保護すればいいかもしれませんが、様々な理由からセルの保護は行わない方針です。

2．課題

このシートを使う作業者を増員することになり、レクチャー用のマニュアルを作っていたところ、細かい作業を少しでも簡略化したいと考えました。
そこで、いくつかの作業をGAS化してみようと思い立ちました。

3．解決するために行ったこと

「前週の内容を削除」では、複数の列を削除します。また、対象列は複数あり、連続した列ではありません。
1列ずつ手動削除…を一発でできるように「対象列の値のみを一括消去するボタン」を作りました。

4．結果、どうだった？

無事作成することができました。
レクチャーの際も「この列と、この列を削除してください。でも、こことここは削除しないように気を付けてください…」のような、ヒューマンエラーが起きそうなフラグ立てまくりの説明を回避することができました。

以下はイメージGIFです。
ボタンの位置は、今回は下に置いてしまいましたが、毎回データ数が変わるのであればヘッダー行が良いかもしれません。

黄色い列が削除対象の列です。
画質の荒いGIFですみません…
スクリプト実行中のアナウンスが録画できなかったので、貼り付けました（笑）

5．作成物

今回書いたコードは以下の通りです。

💡覚えておきたいポイント

・col : 何列目か（A列＝1列目）
・len : そこから連続で何列分を対象にするか（ col: 1, len: 3 とした場合、A列からC列までの3列）

・targetColumns.forEach()
　・targetColumns（データを消去する列のリスト）に対して、
　・forEach : それぞれに同じ処理を行う。

・sheet.getRange(2, range.col, lastRow-1, range.len)
　・2 : 2行目から
　・range.col : 対象となる列番号(targetColumnsで指定したcol)
　・lastRow - 1 : 最後の行の1つ手前まで
　・range.len : その列から何列分(targetColumnsで指定したlen)

引き続き、実務を通して少しずつGASを学んでいきたいと思います。
